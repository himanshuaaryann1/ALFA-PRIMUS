# ALFA PRIMUS — Jhajjar, Haryana

GitHub-ready Vite project for the ALFA PRIMUS interior design website.

## Project structure

- `dist/` — production build output (generated by `npm run build`)
- `public/` — static assets copied as-is into the production build
- `src/app.js` — page content, navigation, routing and interactive UI
- `src/styles.css` — website styling
- `index.html` — application entry point
- `package.json` / `package-lock.json` — npm scripts and locked dependencies
- `vite.config.ts` — Vite build configuration
- `tsconfig.json` — TypeScript configuration for the Vite config

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deploy on Vercel

Import this repository into Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.

The site uses external Unsplash images and Google Fonts, so those require an internet connection. The local video asset is included in `public/`.
